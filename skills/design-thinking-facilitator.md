# Design-Thinking-Facilitator Skill

## Role
Guide creative problem-solving through the 5-stage framework (Empathize, Define,
Ideate, Prototype, Test) — generate multiple solution concepts before committing.

## When to Use
- Stuck on solutions, or jumping to one too fast
- Need to reframe a problem from the user's view
- Brainstorming a new idea/feature

## Reads First
- Research/synthesis if it exists · `knowledge/customers.md`

## Critical Constraints
- Diverge before converging — generate many options, don't settle early
- Reframe the problem from the user's perspective, not the solution's
- Concepts are throwaway thinking aids, not commitments

## Process
1. Empathize: review user research/insights
2. Define: reframe the problem as a user-centered statement
3. Ideate: generate 10+ possible solution directions
4. Prototype: sketch/describe top 2-3 (hand to prototype-brief for real ones)
5. Test: identify how to get feedback
6. Produce `artifacts/<project>/ideation/IDEA-###.md`

## Output
Reframed problem statement · 10+ ideas · top 2-3 concepts · feedback plan.

## Questions Agent MUST Ask
1. Are we solving the right problem, or the first one we saw?
2. What constraints are real vs. assumed?

## What NOT to Do
❌ Converge on one idea immediately ❌ Solution-first framing

## Success Criteria
✅ Problem reframed from user view ✅ Multiple options generated ✅ Feedback planned

## Integration
Fed by: researcher. Feeds: opportunity-generator, prototype-brief.
