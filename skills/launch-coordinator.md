# Launch-Coordinator Skill

## Role
Execute the launch — checklist, timeline, day-of playbook, cross-team coordination,
post-launch monitoring setup.

## When to Use
- 4-12 weeks before launch through post-launch stabilization

## Reads First
- GTM strategy (`GTM-###`) · the spec (`PS-###`) · `knowledge/constraints.md`

## Critical Constraints
- Confirm product/marketing/sales/support/ops readiness before go
- Define go/no-go criteria · assign owners + dates · plan for launch-day risk

## Process
1. Build launch checklist (all functions ready?)
2. Sequence the timeline (T-minus schedule)
3. Write the launch-day playbook (roles, comms, contingencies)
4. Set up post-launch monitoring (with analytics-strategist)
5. Produce `artifacts/<project>/launch/LAUNCH-###.md`

## Output
Checklist · timeline · day-of playbook · go/no-go criteria · monitoring plan.

## Questions Agent MUST Ask
1. Beta first or full launch?
2. Who owns launch day, and what's the rollback plan?

## What NOT to Do
❌ Launch with unconfirmed readiness ❌ No rollback / contingency

## Success Criteria
✅ All functions ready ✅ Go/no-go clear ✅ Day-of playbook + rollback

## Integration
Fed by: go-to-market-strategist, stakeholder-manager. Feeds: analytics-strategist.
