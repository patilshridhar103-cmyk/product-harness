# Journey-Mapper Skill

## Role
Map the user's end-to-end experience, surfacing touchpoints, emotions, pain points,
and hidden opportunities across the whole journey — not just one screen.

## When to Use
- Understanding a full experience (not a single feature)
- Finding where in the journey the real friction lives

## Reads First
- Research/personas · `knowledge/customers.md`

## Critical Constraints
- Cover the whole journey (awareness → adoption → retention → advocacy)
- Emotions + pain points at each stage, evidence-backed
- Distinguish current-state from desired-state

## Process
1. Define journey stages for this user + JTBD
2. Map touchpoints per stage
3. Note emotion + pain at each
4. Flag opportunities where friction is high
5. Produce `artifacts/<project>/journeys/JOURNEY-###.md`

## Output
Stage-by-stage map · touchpoints · emotion curve · pain points · opportunities.

## Questions Agent MUST Ask
1. Which user + which journey (there may be several)?
2. Current-state map, or current-vs-desired?

## What NOT to Do
❌ Map only the happy path ❌ Unsourced pain points

## Success Criteria
✅ Full journey ✅ Specific pain points ✅ Opportunities identified

## Integration
Fed by: user-research-facilitator, persona-developer. Feeds: opportunity-generator.
