# PRI-H-001 — Hypothesis: Structured Tool Cuts Prioritization Time

**Project:** PRI · **Type:** Hypothesis · **Date:** 2026-08-14
**Skill:** hypothesis-validator · **From:** PRI-OPP-001 (O-001)

---

## Statement
**If** we give PMs a structured prioritization tool that weights criteria,
**then** time spent prioritizing drops ≥80% (4 hrs → ~48 min/week),
**for** SMB product managers.

## Success (TRUE if)
- Users report <1 hr/week (≥80% reduction)
- ≥70% of test users say "would use this"

## Failure (FALSE if)
- Still ≥3 hrs/week, or <30% would adopt

## Assumptions
- A-1: pain is structure, not business-value clarity (the one E-001 must resolve)
- A-2: users will switch off spreadsheets
- A-3: 80% reduction is achievable (later proved optimistic — actual ~37%)

## Test
Recommended Wizard-of-Oz, 3 customers, 1 week → became PRI-E-001.
